### 3. Three.js globe behaviour (horizon-style camera)

* Create a standard Three.js **scene, camera, and WebGLRenderer** attached to `#hero-globe-canvas`.
* Position the camera so:

  * You see the **top half** of the globe.
  * The camera looks slightly down at the Earth, similar to a satellite view.
* Add:

  * Sphere geometry for Earth.
  * Textured or coloured material with blues/whites to resemble Earth.
  * A slightly larger, transparent sphere or halo around it for the **atmospheric glow** on the rim.
* Lights:

  * One main directional light (simulating the sun) coming from above/side.
  * Soft ambient light.
* Use **OrbitControls**:

  * Rotation via drag.
  * Zoom via scroll.
  * Limit the controls so the user doesn’t spin the camera underneath the planet (keep it planet-like, not weird angles).
* Idle rotation:

  * When user isn’t interacting, the globe slowly rotates around its Y axis.

Make sure the renderer resizes properly with the hero container (responsive canvas).

### 4. Add anime.js for smooth motion

Use **anime.js** to give the hero globe polished motion, without changing the rest of the page.

#### a) Setup

* Install:

  ```bash
  npm install animejs
  ```

* Import in your hero script:

  ```js
  import anime from "animejs/lib/anime.es.js";
  ```

* Use a state object the renderer reads every frame:

  ```js
  const globeState = {
    rotationY: 0,
    rotationX: 0,
    zoom: defaultCameraZ,
    scale: 1
  };
  ```

  In your render loop:

  ```js
  globe.rotation.y = globeState.rotationY;
  globe.rotation.x = globeState.rotationX;
  globe.scale.set(globeState.scale, globeState.scale, globeState.scale);
  camera.position.z = globeState.zoom;
  ```

#### b) Intro “rise from space” animation

When the page loads, animate the globe so it feels like it’s **rising into view and settling**, like in the WebGL Earth banner:

* Start with:

  * Slightly smaller scale.
  * Camera a bit further away.
* Animate to:

  * Final `zoom` (closer).
  * `scale: 1`.
  * Slight adjustment of `rotationY`.

Example:

```js
anime({
  targets: globeState,
  zoom: [defaultCameraZ + 4, defaultCameraZ],
  scale: [0.8, 1],
  duration: 1600,
  easing: "easeOutExpo"
});
```

#### c) Hover glow / tilt

On hover over `#hero-globe-container`:

* Slightly increase `scale`.
* Add a tiny `rotationX` tilt (toward the viewer).
* Optionally intensify a uniform controlling atmosphere brightness if you expose it.

```js
const globeContainer = document.getElementById("hero-globe-container");

globeContainer.addEventListener("mouseenter", () => {
  anime({
    targets: globeState,
    scale: 1.05,
    rotationX: globeState.rotationX + 0.08,
    duration: 400,
    easing: "easeOutQuad"
  });
});

globeContainer.addEventListener("mouseleave", () => {
  anime({
    targets: globeState,
    scale: 1,
    rotationX: 0,
    duration: 400,
    easing: "easeOutQuad"
  });
});
```

#### d) Click-to-focus zoom

On click of the globe area, toggle between default zoom and slightly closer:

```js
let focused = false;

globeContainer.addEventListener("click", () => {
  focused = !focused;
  anime({
    targets: globeState,
    zoom: focused ? defaultCameraZ - 3 : defaultCameraZ,
    duration: 600,
    easing: "easeInOutQuad"
  });
});
```

Idle rotation can still run each frame; anime.js just smoothly modifies the state.
