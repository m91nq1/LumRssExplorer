Create a Search & Explore page for my LUM News project.

Goal

Build a React + TypeScript page/component called SearchExplorePage that implements this feature:

Search & Explore

Search bar with suggestions for topics, entities, and sources.

Results displayed as stories and/or articles, with filters on the left or top.

Ability to switch between story-centric and article-centric views.

Make it highly interactive, using a black / dark background, indigo accents, and white text, with smooth hover and focus effects everywhere.

You can assume this will be integrated into an existing LUM News dashboard, but for now you can mock the data in the frontend or call a fake /api/search endpoint.

Tech & structure

Use React + TypeScript.

Use CSS modules or a single SearchExplore.css file for styling (no Tailwind unless it already exists in the project).

The main component should be SearchExplorePage, which I can import and render inside a router or layout later.

Use functional components and hooks (useState, useEffect).

Create small, reusable components:

SearchBar

SearchSuggestions

FiltersPanel

ViewToggle

StoryCard

ArticleCard

ResultsGrid

EmptyState

LoadingState (skeletons)

If needed, create a simple mock API module that returns fake stories and articles so I can see everything working.
